# История версий и уровень подтверждения

Официальные описания — из сохранённого каталога KingSong от 2026-09-23. Полные оригиналы, ссылки и оговорки о датах: `s22-developer-pack/HISTORY_RU.md`. Ниже отдельная колонка для результатов нового бинарного анализа.

Для всех 15 образов заново проверены хеши, расшифровка, распаковка RAM, метаданные диагностических записей и пять начальных параметров. Сравнение соседних версий эвристикой выполнено для навигации; неподтверждённые кандидаты не объявляются установленными изменениями.

Обе правки исполнены в эмуляторе; дополнительно проверен приём 93/104-байтных ответов BMS на ожидаемую команду 0x42. Весь новый батарейный протокол не восстановлен. |

Разбор не позволяет объявить поздние версии предназначенными только для новых моторов/плат. В частности, 2.36 и 2.41 содержат изменения вычислительной логики управления. Аппаратные условия достижения этих веток и полная матрица совместимости ещё не установлены.
