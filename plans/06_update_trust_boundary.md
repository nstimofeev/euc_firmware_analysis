# Обновление и границы проверки образа

Прочитать `plans/EXECUTION_RULES_RU.md`.

Модель: `gpt-6-luna`. Исключительное поддерево записи: `research/update-trust-boundary/`.

## Задание

Инвентаризировать реально имеющиеся приложения, APK/код обновлятора и возможные фрагменты загрузчика для S22/16X. Входы research/update-path, s22-platform-research, s22-research, ks16x; соседние scratch-каталоги только чтение. Раздельная таблица: AES файла, CRC транспорта, служебные Flash-флаги/переходы, проверка целостности приложения, криптографическая подпись. Указывать для каждого пункта адрес/файл/источник или неизвестно. Искать конкретные ссылки на низкую область Flash вне приложения и определить требуемый диапазон отсутствующего кода. Не делать вывод unsigned по отсутствию строк crypto. Цель первой волны — точная карта доказательств/недостающих артефактов, не спекулятивный взлом загрузчика.

## Критерий первого результата

Воспроизводимый завершённый срез, адресные доказательства, честный список оставшихся вопросов и `STATUS.json` согласно общим правилам.
