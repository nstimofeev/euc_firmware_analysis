# Выбор конфигурации 16X

Прочитать `plans/EXECUTION_RULES_RU.md`.

Модель: `gpt-6-sol`. Исключительное поддерево записи: `research/ks16x-configuration/`.

## Задание

Проследить ссылки на KS16X1, KS16X4, KS16X9 в трёх образах 212/220/223. Найти потребителей строк и проверить: это сравнение ID, формирование идентификатора, ветка загрузки настроек или другое. Использовать собственные RAM/диагностические таблицы 16X, Capstone; если нужен Ghidra — отдельный проект/экспорт только в своём поддереве. Первый результат должен содержать точные xref и минимум один разобранный потребитель, отдельно неизвестные мотор/плата/батарея. Не приравнивать три версии трём платформам и не выводить модель MCU только из Cortex-M3.

## Критерий первого результата

Воспроизводимый завершённый срез, адресные доказательства, честный список оставшихся вопросов и `STATUS.json` согласно общим правилам.
